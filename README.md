# 📄 PDF Tools - Merge & Split

A free web app to merge, split, extract, and rotate PDF files.

## Features

✅ **Merge PDFs** - Combine multiple PDF files into one  
✅ **Split PDF** - Split into individual pages or custom ranges  
✅ **Extract Pages** - Extract specific pages from a PDF  
✅ **Rotate Pages** - Rotate pages by 90°, 180°, or 270°  

## Privacy

🔒 All files are processed in your browser. No files are uploaded to any server.

## Usage

1. Select a tool from the sidebar
2. Upload your PDF file(s)
3. Configure options
4. Download the result

## Tech Stack

- Python
- Streamlit
- PyPDF2

## Deployment

Deployed on Streamlit Cloud - completely free!
